# miketineo/homebrew-tap

Homebrew formulae for [@miketineo](https://github.com/miketineo)'s tools.

## Install

```sh
brew tap miketineo/tap
```

## Available formulae

### chmoji

`:shortcode:` emoji expansion and auto-popup picker for zsh.

```sh
brew install miketineo/tap/chmoji
```

After install, add the source line from `brew info chmoji` to your `~/.zshrc`.
See the [chmoji repo](https://github.com/miketineo/chmoji) for usage.
